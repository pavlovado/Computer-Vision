# 🧠 Классификация изображений с помощью CNN

Этот проект демонстрирует, как с помощью сверточной нейронной сети (CNN) можно обучить модель для классификации изображений. Весь процесс реализован в формате Jupyter Notebook.

 **Файл блокнота:** `CNN.ipynb`  
[ Открыть в Google Colab](https://colab.research.google.com/drive/1ZtjtZHsztpEhbleEo3jDLRBByzzMLBRd?usp=sharing)

---

## 🚀 Возможности проекта

-  Загрузка и предобработка изображений
-  Построение архитектуры CNN с Keras
-  Обучение модели на тренировочных данных
-  Визуализация точности и потерь
-  Оценка точности на тестовой выборке
-  Предсказание класса новых изображений
